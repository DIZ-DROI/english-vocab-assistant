Smart English Vocabulary
初中英语单词智能听写助手

公网访问地址：
https://diz-droi.github.io/english-vocab-assistant/

作品类型：Web/H5 单页应用
适用平台：Chrome / Edge / Firefox / Safari（推荐 Chrome/Edge 以获得完整语音功能）
无需安装，浏览器直接打开即可使用

一、访问方式

  1. 使用任意现代浏览器打开上述公网地址
  2. 首次使用时，浏览器可能请求麦克风权限（用于跟读评测功能），请点击"允许"
  3. 所有数据存储在浏览器本地（localStorage），无需注册登录

二、操作步骤

2.1 添加单词

方式一：从题库选择 — 点击首页"📚 从题库选择单词"，按年级/单元勾选课本词汇加入听写列表
方式二：手动输入 — 在首页英文/中文输入框逐条添加单词
方式三：批量粘贴 — 支持格式：apple 苹果 或 book,书 或 cat:猫
方式四：上传TXT文件 — 每行一个单词，英文与中文以空格/逗号/冒号分隔

2.2 听写练习

步骤1：在首页设置语速（0.5x - 2.0x）、口音（美式/英式）、听写轮次
步骤2：点击"开始听写"按钮，系统自动朗读英文单词
步骤3：在输入框中拼写听到的单词，系统自动判定正误
步骤4：完成一轮后查看成绩报告，可查看错误单词详情

2.3 智能单词机（核心功能）

步骤1：进入"📖 背诵计划"页面，从9本词书中选择所需词库，点击"加入计划"
步骤2：点击首页"📱 智能单词机"卡片，调整每日目标背诵量（10-50词）
步骤3：点击"开始背诵"，进入四步学习循环：
单词初记 → 例句跟读评测 → 拼写检测 → 复习巩固
步骤4：系统基于艾宾浩斯遗忘曲线自动安排复习，间隔为 1/2/4/7/15/30 天

2.4 语音跟读评测

步骤1：在例句跟读步骤，点击"🎤 开始跟读录音"按钮
步骤2：浏览器请求麦克风权限，允许后大声跟读显示的例句
步骤3：点击"⏹ 结束录音并评分"，系统自动从发音准确度、重音语调、流畅度、音节完整性四个维度评分
步骤4：查看百分制综合得分、各维度进度条、发音偏差标注和优化建议

三、核心功能

📚 9 本词书

新概念英语1-3册、人教版初中英语、中考核心词汇(1500+词)、初中短语搭配(300+条)、不规则动词表、场景分类词汇(8大主题)、KET核心词汇(1500+词)

📱 智能单词机

四步学习法 + 艾宾浩斯遗忘曲线，科学安排每日新学与复习，自动推送到期复习内容

🎤 语音跟读评测

MediaRecorder + SpeechRecognition 双通道采集，四维度评分（准确度/重音语调/流畅度/音节完整性），逐词偏差标注

🔊 TTS 语音合成

Web Speech API 驱动，支持美式/英式发音切换，语速 0.5x-2.0x 可调

📝 听写检测

自动朗读 → 用户拼写 → 实时判定正误，支持多轮复习，错词自动汇总

💡 学习辅助

每个单词展示固定搭配和高频考点，来源于 LOCAL_DICT 详细词典

📊 学习统计

记录累计学习词数、待复习词数、已复习词数，每日目标进度可视化

⏱ 自动背诵

音频播放后5秒自动倒计时切换到下一环节，无需手动点击，沉浸式学习体验

四、适用场景

场景说明

中考备考冲刺中考核心词汇按考频分级（Lv.1必考→Lv.3高频），高效复习

日常英语听写练习支持手动添加/批量导入自定义词汇，灵活适配任意教材
口语发音矫正语音跟读评测提供逐词偏差分析和多维度改进建议

五、技术说明

  • 前端框架：纯 HTML5 + JavaScript（无框架依赖，单文件架构）
  • 样式：Tailwind CSS CDN
  • 语音：Web Speech API (SpeechSynthesis + SpeechRecognition)
  • 录音：MediaRecorder API
  • 存储：浏览器 localStorage（数据仅保存在用户设备上）
  • 部署：GitHub Pages（HTTPS，全球 CDN 加速）
  • 评分算法：Levenshtein编辑距离 + LCS最长公共子序列 + 元音音节匹配

六、注意事项

  • 语音跟读评测功能需使用 Chrome 或 Edge 浏览器（Firefox/Safari 的 SpeechRecognition 支持有限）
  • 首次使用需允许麦克风权限
  • 建议在安静环境中使用语音评测功能以获得准确的评分结果
  • 本地数据清除后学习记录将丢失，建议定期导出备份
